# Pine 1.3.0 (10)

- `Pine-1.3.0-10-unsigned.ipa`: device Release package including the Live Activity
  extension. Import through the existing SideStore signing flow.
- `Pine-1.3.0-10-source.zip`: the native source distribution delivered with this
  build; the full repository also contains backend, web UI and recovery files.
- `validation.json`: recorded build/core-check results. Paths in this historical
  receipt refer to the original Mac workspace; see `SHA256SUMS` for archived files.

Device and simulator compilation passed, along with 24 core checks. Simulator
runtime acceptance was stopped at the user's request. Visual/motion acceptance
and physical-device FPS were not measured. This archive does not claim otherwise.
